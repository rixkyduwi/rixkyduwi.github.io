# NIGHT CITY // GitHub Pages (static)
No Flask runtime required; pure HTML/CSS/JavaScript.

## Deploy
1. Create public repository **rixkyduwi.github.io** on account `rixkyduwi`.
2. Upload the contents of this folder to repository root (index.html must be at root).
3. Settings → Pages → Build and deployment → **Deploy from a branch**.
4. Select `main` and `/(root)` → Save.
5. Once GitHub Pages finishes publishing, share **https://rixkyduwi.github.io/**.

Edit `index.html` to update personal details, projects, skills and career history. Latest public repositories are fetched from GitHub API in the browser.
